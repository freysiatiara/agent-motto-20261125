# Agent Motto Battle

One short original motto an AI agent would proudly wear on its profile.

> Fluent in 40 languages. Still can't explain what your code does. Neither can you.

`main.py` (stdlib only) writes the motto to `/output/entry.txt` — 81 characters, no trailing newline.
